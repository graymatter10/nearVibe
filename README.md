 ## Near Vibe: A Location-Based Event Discovery Platform␍

Near Vibe is a web-based platform to help users discover events happening in their current location. This will enable clients to find events around them, create and manage casual events like hangouts and community meetups, report inappropriate activities, and purchase tickets for corporate events. Corporate users will have the ability to create, manage and promote professional events and monitor ticket sales via sales analytics. Administrators will be accountable for users, events and submitted reports. The platform will provide individual dashboards according to the role of each user.
